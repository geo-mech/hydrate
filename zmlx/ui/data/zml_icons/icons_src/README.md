# zml_icons 图标源文件

`zml_icons/` 里的工具栏图标是**从代码生成的**，不是手画的位图。

| 文件 | 作用 |
|---|---|
| `shapes.py` | **唯一的源**：每个图标一段 24×24 的 SVG 坐标图形（加一个 key 就是加一个图标） |
| `build.py` | 把 `shapes.py` 渲染成 PNG + ICO，写进上一级目录 |
| `svg/<name>.svg` | `build.py` 顺带写出的 SVG 源文件，可用浏览器单独打开预览 |
## 用法

在仓库根（`projects/zml/`）下：

```bash
python zmlx/ui/data/zml_icons/icons_src/build.py
```

## 产物约定（上一级目录）

| 文件 | 说明 |
|---|---|
| `<name>.png` | 工具栏图标，**每个图标只有这一张**：128×128、**透明底**，只有图形本身 |
| `app.png` | **应用图标**（窗口图标 `load_icon('app')`）：128×128，自己就是完整画面（整块渐变圆角方块） |

**为什么是 128px 一张**：显示时由 Qt 缩放到工具栏的实际尺寸（本机实测工具栏取 24px），
存一张 128px 足够清晰，也不用在仓库里堆 16/24/32/48 好几份。

**为什么底色透明**：图标会出现在工具栏、菜单、标签页等不同底色的地方（浅色 / 深色主题），
画一块固定底衬等于强行给它们配一个颜色；透明之后图形跟随所在位置，哪里都不会露出方块。

## 风格约定

- 图形控制在 24×24 内、描边 2px、圆角端点；
- 颜色只有一套语义色：蓝=文件、绿=运行/成功、琥珀=暂停/导出、红=停止/危险、
  天蓝=刷新/导入、深石板=设置/系统；
- 早期那批图标是 jpg（没有透明通道，边缘带白边毛刺）且是拟物 3D 风格，缩到 24px 就只剩一团色块。

## 注意事项

- **`shapes.py` 里的 key 就是 `settings.load_icon(name)` 的 `name`**：
  `zmlx/ui/main.py` 与各插件的 `add_action(..., icon=...)` 都按名字引用，改名等于改 API。
- 这里**只新增文件**，不删除任何东西；确认新图标可用后，旧位图由人手动删。
- `settings.load_icon(name)` 依次找 `<name>` → `<name>.png` → `<name>.jpg`（见 `settings.find_icon_file`），
  所以**外部图标目录**里的老位图照样能用。
- `app` 曾经与 `iggcas` 是同一个文件（所徽），现在 `app` 换成了独立的应用图标，`iggcas` 保持不变。
