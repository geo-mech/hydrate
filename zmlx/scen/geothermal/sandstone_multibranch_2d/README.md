# 砂岩二维平行多分支井对照

## 使用

在IDE中直接运行 `case_multibranch.py`：默认顺序计算N1、N2、N3、N4，均为10年，保存数据但不出图。计算完成后单独运行 `plot_multibranch.py`，终端打印图片及表格位置。

也可在本文件夹终端运行：

```powershell
python case_multibranch.py --case all
python plot_multibranch.py
```

单组运行例如 `python case_multibranch.py --case N4`。已有非空工况结果目录时拒绝覆盖；修改参数重算前，请先重命名旧 `results` 目录。全部对比工况须使用同一组参数、井距、网格和运行天数。

## 模型与引用

- 直接调用 `geothermal/_well_cross_section.py` 的 `create`、`solve` 和新增的 `get_well_cells`，不复制热流求解器；网格、水物性、场保存继续调用原模块。
- `settings.py` 引用 `case_sandstone_10years.py` 的PERM、COND，保留2960m、85.8℃、2.35℃/100m、k=3×10⁻¹³m²、λ=3.015319W/(m·K)、φ=0.22、ρ=2600kg/m³、cp=825J/(kg·K)。水物性仍用原砂岩275～370K经验表，未新增依赖。
- X、Z各±50m，101×101网格，Y厚1m。分支沿Y平行延伸，在同一深度横向排列。井径0.2m，所有井初温280K，热容放大10⁶倍，井壁密封。无侧向水头差；外水力边界封闭，左右大热容地温缓冲。
- 井外地下水迁移、岩石导热及岩水换热保留。未解析分支交汇、放射状轨迹、井内流量分配或出口温度。
- N1使用中心井，与原砂岩基准的几何、参数及能量统计一致；新组需要自己运行N1以确保同配置。未假定已完成数值一致性验证。

## 输出数据

每个 `results/N*/` 保存：

- `parameters.json`：建模参数与实际井位，求解前写入。
- `daily.csv`：每日合计功率/累计热量、合计除以N的结果、每条分支的功率/累计热量。
- `fields_day_0365.npz`、`fields_day_1825.npz`、`fields_day_3650.npz`：第1/5/10年岩石温度、水温、密度、z₀及井位等。所有井单元均在流体场内屏蔽。保存器兼容原速度字段，但新plot不输出达西流速图。
- `summary.json`：计算结束后写入，包括合计功率、累计热量及各井温升。

功率以每条井单元的 `mc×T` 储能增量分别计算，再求和，避免只统计第一条井。CSV中原字段 `daily_power_w_per_m`、`cumulative_heat_kwh_per_m` 在多井情况下表示**各分支沿共同轴向1m的合计**，分别为W/m、kWh/m；`mean_branch_*` 表示合计/N，对应每米总换热井长的平均能力。前者增加并不必然说明后者提高。

独立绘图脚本在 `results/plots/` 输出合计/单位总井长功率和累计热量曲线、各井功率曲线、1/5/10年温度-z₀组合对比图、N1第1/10年组合图及末日累计热量/增幅柱状图。温度coolwarm，z₀为viridis，六色带加等值线，共用色标，方形子图、深度向下、微软雅黑14号、刻度朝内。井周2m圆仅用于清楚显示位置，不是真实井径或换热半径。

`results/tables/` 输出逐日对比CSV、关键年份CSV和末日Markdown评价表。其中参考比为 `Q_N/(N×Q_1)`，对照相同井温的独立单井叠加参考。该值小于1说明比理想叠加少，但温度相关地下水运动、边界与不同井位也会影响该值；不能将它直接当作纯热干扰贡献率，也不强制限定在0～1。

## 计算量与边界

默认四组都使用10201个单元，增加的是低温井单元数，不增加第三维网格。新算例关闭每个内部时间步的功率文本历史，只保留逐日数据，减少长周期重复序列化；物理求解仍由原tfc迭代完成。增加井数可能改变自适应步长，因此不承诺运行时间完全不变。

默认100m域用于与原基准一致的快速筛选。N4最外侧井距侧边界约20.3m，10年结果尤其可能受到左右热缓冲补热影响。正式定量结论需所有工况统一扩大域检查，例如 `--half-width 100 --grid 201`（约保持原分辨率，但单元数增加约4倍）。切勿只对N4扩大域后与原域N1直接比较。

参数入口：`settings.py`。可使用 `--days`、`--spacing`、`--half-width`、`--grid` 控制时长、井距、计算域和网格。默认只比较分支数量；当前热汇模型没有循环流量，所以不包含“固定总流量”或“等分流量”设定。

本次交付只作静态检查及模拟对象的结构/能量统计检查，不运行任何地热模型或生成实际结果图。
